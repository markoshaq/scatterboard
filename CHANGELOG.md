## [0.1.0] - 2026-11-03

First public release.

- Infinite-canvas boards on a dot grid, with 17 card types: notes,
  headings, to-dos, links, video/audio/map embeds, nested boards,
  columns, comments, colour swatches, documents, tables, sketches,
  annotations, images and files, plus connector lines.
- Rich text with markdown autoformat, and a dedicated document editor
  with word count and Word, Markdown and plain-text export.
- Tables with typed cells and six formulas (SUM, IF, MIN, MAX, COUNT,
  AVERAGE).
- Drawing: pressure-sensitive sketch cards, drawing on images, board
  draw mode, and an image editor for crop, rotate, flip and
  background cutout.
- Organization: labels, emoji reactions, comments, an Unsorted inbox,
  Trash with restore, board search, templates, quick capture, synced
  note copies, dark mode, a per-board dot-grid toggle and
  presentation mode.
- Export: board PNG, standard and high-quality PDF, Word, Markdown,
  plain text, a media zip, and full-board JSON for backup or
  device-to-device sync.
- Local-first and offline: boards live in the browser and nothing
  phones home; installable as an app. The only online extras, link
  previews and embed players, are off by default.
- UI in English, Deutsch, Español, Français and Português.
